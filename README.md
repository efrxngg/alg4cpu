# Alg4cpu

Descripción general
Alg4cpu es un proyecto desarrollado en Angular 20 con soporte de Node.js 22.19.0, diseñado para la simulación de ejecución de procesos bajo diferentes algoritmos de planificación de CPU.


## Tecnologías empleadas

* Frontend: Angular 20, PrimeNG, Tailwind CSS
* Backend: Node.js 22.19.0
* Entorno: NPM, TypeScript
